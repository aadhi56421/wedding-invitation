# Fairooza & Adil — Nikkah Invitation

A simple, elegant wedding invitation site built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- Full-bleed photo hero with a live countdown to the Nikkah
- Couple, event, and venue details with a Google Maps "Get Directions" link
- Photo gallery and closing dua

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run preview  # preview the production build
```
